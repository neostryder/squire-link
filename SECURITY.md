# Security

Open the Squire Link repository's Security tab on GitHub and choose Report a vulnerability to contact the maintainers privately. If GitHub does not offer that option, open an issue asking for a private contact and leave out exploit details and secrets.

Squire Link listens only on a loopback address, so it does not accept network connections from other computers. A program already running on the same computer can connect to it. The browser origin list permits selected web pages to call the proxy; it does not authenticate local programs. In serve mode, model and order requests need the link token, and so do all requests without a browser origin.

The proxy sends requests only to configured server targets and fallbacks. API keys, the Discord bot token, and the optional link token live in the operating system keychain. Logs omit secret values, request and response bodies, and chat order text. Logs include route targets and accepted chat viewer names.
